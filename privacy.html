SmokeRoach Bot privacy policy

Last updated: 17 October 2026

SmokeRoach Bot is a private tool used only by the owners of the SmokeRoach YouTube channel to manage their own channel. It is not available to other users.

What data it accesses

With the channel owner's permission, through Google's YouTube Data API, it reads the channel's own videos, playlists and channel details, and makes changes to them (such as titles, descriptions, tags and playlists) only when the owner approves.

How data is used and stored

Data is used only to help manage the SmokeRoach channel. Access tokens are stored privately and are never sold or shared with third parties. No data from other YouTube users is collected.

SmokeRoach Bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Removing access

Access can be revoked at any time from Google account permissions.

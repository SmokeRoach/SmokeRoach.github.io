SmokeRoach Channel Manager privacy policy

Last updated: 17 October 2026

SmokeRoach Channel Manager (also shown as "SmokeRoach Bot") is a private tool used only by the owners of the SmokeRoach YouTube channel to manage their own channel, with the help of their AI assistant. It is not offered to the public and has no other users.

YouTube API Services

SmokeRoach Channel Manager uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Information is handled by Google as described in the Google Privacy Policy.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What data it accesses

With the channel owner's permission (Google sign-in, scope youtube), it accesses only the SmokeRoach channel's own data through the YouTube Data API:

  • Channel details and branding (name, description, banner)
  • The channel's own videos and their details (titles, descriptions, tags, thumbnails, privacy status)
  • The channel's own playlists and playlist items
  • Public statistics for the channel's own videos (views, likes, comment counts)

It does not access, collect or store data about other YouTube users or channels.

How the data is used

Data is used only to manage the SmokeRoach channel: uploading the owners' own videos and Shorts, editing titles, descriptions and tags, managing playlists, setting thumbnails and banners, and checking how the channel's videos are performing. Changes are made only when the channel owner approves them.

How the data is stored

The Google sign-in tokens are stored privately on the owners' own computer with restricted access, and are used only to call the YouTube API for this channel. Any copies of YouTube API data (for example a backup of a video's details before an edit, or a snapshot of view counts) are kept only as long as needed, and are deleted or refreshed within 30 days.

Sharing

No data is sold, shared with or disclosed to any third party, and none is used for advertising.

Removing access

You can revoke SmokeRoach Channel Manager's access to your Google account at any time from the Google security settings permissions page. Once access is revoked, the stored tokens stop working and are deleted.

Deleting your data

To ask for any stored data to be deleted, email smokeroach0151@gmail.com. We will delete it within 7 days and confirm by email.
